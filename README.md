# Simulateur boursier

Application Windows de simulation de portefeuille boursier (utilisateurs, actions, achats et ventes, suivi des avoirs). Projet réalisé sous la direction du Prof. Idrissi, en binôme avec Dia Fetnassi : conception d’une architecture backend/frontend et d’un modèle de domaine modélisé en UML. Projet en cours de développement, avec des fonctionnalités supplémentaires envisagées.
